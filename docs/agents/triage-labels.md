# Triage labels

| 标准角色        | GitHub 标签     | 含义                     |
| --------------- | --------------- | ------------------------ |
| needs-triage    | needs-triage    | 等待维护者评估           |
| needs-info      | needs-info      | 等待补充信息             |
| ready-for-agent | ready-for-agent | 规格充分，可交给代理执行 |
| ready-for-human | ready-for-human | 需要人工实现             |
| wontfix         | wontfix         | 不予实施                 |

技能提及标准角色时，使用对应的 GitHub 标签。
已有标签直接复用，缺少时创建同名标签。
