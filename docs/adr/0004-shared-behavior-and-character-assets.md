# 用共享行为和预制角色素材支持单宠物切换

2026-10-26 确认以下待实施的决定：桌面始终只显示一只宠物，用户通过设置选择角色。沿用 [ADR-0002](0002-desktop-pet-architecture-boundaries.md) 的行为与表现边界，通用行为由同一套逻辑管理，各角色用自己的素材表达这些行为；切换时加载预先制作的角色素材，不在运行时生成图片。

这个选择避免为不同身体结构的角色分别维护整套行为逻辑，代价是每个角色都需要提供并验证当期通用动作的表现、播放节奏和对齐数据。通用动作表达行为类别，各角色可采用不同姿态，也可在合理的动作之间复用素材；素材缺失不能默认为该能力已完成。角色素材包仍是项目内部的素材组织边界，不承诺公共导入格式。

角色选择作为持久化偏好保存；本轮本地验收在尚无角色选择记录时默认鲸鱼娘，之后恢复上次保存的选择。切换保留大小、位置、朝向和隐藏状态，新角色从待机开始；拖拽、下落或攀爬中的切换等宠物站稳后执行。新素材成功加载后才替换当前角色，加载失败保留原角色与选择。这个边界放弃跨角色延续动作进度，避免不同角色的姿势、帧数和落脚点在动作中途不匹配。

角色制作同时保留角色设定、动作提示词、实际使用的参考图、最终采用的原图及加工记录，并关联输入与产物。提示词用于追溯和继续迭代，不能代替已选定的素材，也不保证重新生成会得到相同结果。

本决定的实施与验收由 [#47](https://github.com/Frost-96/mosey/issues/47) 跟踪。
