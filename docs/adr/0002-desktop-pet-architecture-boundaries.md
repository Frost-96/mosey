# 桌面宠物的语言、动画与行为边界

2026-10-20 技术栈访谈中，用户确认主体采用 TypeScript，允许为 Electron 无法满足的系统能力引入必要且集中封装的原生适配；引入前需说明用途、替代方案和维护成本。这接受少量跨语言维护成本，避免把“TypeScript 生态”误解为禁止原生代码，也不表示 Dock 检测已经可行。

首版角色采用逐帧图片，程序负责桌面移动与下落，不采用骨骼动画工具链。用户明确后续主要增加动作种类，当前选择 Canvas 2D；未来大量对象同时运动、独立部件和特效出现时再评估 PixiJS，不预先实现第二套渲染器。行为采用 XState 表达显式状态与转换规则，明确睡眠、点击、拖动及下落之间的打断关系；接受学习与依赖成本，避免自行扩建状态机框架。角色姿态与系统可见性分别建模。

主进程管理行为状态、桌面位置和系统适配；渲染进程负责素材播放与绘制。行为模块保持纯 TypeScript，不依赖 Electron；preload 通过 contextIsolation 和 contextBridge 暴露有限、明确的消息接口。逐帧绘制留在渲染进程，不通过 IPC 逐帧传图片；输入、窗口移动与画面同步仍需验证。

按当前宠物窗口和菜单栏范围选型，暂不引入 React 或 Vue。未来出现明确的复杂设置窗口需求时再评估，设置界面与角色渲染可分别选型。

工程构建与打包统一采用 Electron Forge，使用官方 Vite 插件，不采用单独的 electron-vite 方案。用户已知官方 Vite 插件仍标为实验性、次版本可能含破坏性变更，并接受锁定版本、升级时验证开发启动及打包产物的兼容性成本。TypeScript 类型检查独立运行。

首版暂定由主进程管理带版本号的 JSON 配置文件，不引入数据库，并考虑写入中断和损坏恢复。大小与手动显示／隐藏意图跨重启保留；开机启动以系统实际设置为准，不持久化动作、拖动或下落。启动时重新计算主屏地面，从稳定休息状态开始。

测试采用 Vitest 作为运行器，Playwright Electron API 作为真实应用驱动，不再以 Playwright Test 作为运行器。用户已知这是需要接好应用启动、退出和失败截图的工程组合，且 Playwright 的 Electron 支持仍标为实验性；具体版本兼容性需验证。整应用外部行为的既有验收边界保持不变，不因选择 Vitest 自动新增内部实现的镜像测试，也不以普通浏览器测试替代真实 Electron 验收。真实跨应用输入、焦点、Dock 与工作区继续单独留证。

用户进一步确认采用 Zod 校验配置、素材描述和跨进程消息；素材采用按动作组织的 PNG 图集、版本化 JSON 描述及 sharp 制作管线，首版不承诺公共角色包格式。首版仅交付 Apple Silicon，Intel 列为后续目标。原生适配先明确平台接口，依据 Dock／输入探针结果选择桥接方式，不提前承诺某条路线可行。

用户进一步确认原生 Electron IPC 配合共享 TS 契约与 Zod，不引入 RPC 框架；源码使用 import/export，主进程与渲染产物优先 ESM，沙盒 preload 输出兼容 CommonJS 单文件。渲染侧按经过时间选帧、按需重绘，主进程负责运动与落地；首版不引入通用物理或动画库。

用户已确认单包工程、单实例与有限故障恢复：重复启动不创建第二只宠物或改变隐藏意图；渲染进程崩溃自动恢复一次，再次失败保留菜单栏重试／退出，主进程崩溃则退出，不引入独立守护程序。资源指标先建立测量基线，再确认数值预算。

用户在最终汇总后要求将 Q1–Q28 方案落为规格。以上是已确认目标，不代表现有实现已经迁移；系统验收范围、版本策略、包管理、代码检查、日志、CI 等工程约定与验证项见 [技术栈确认记录](../technical-stack.md)。

2026-10-25，#11 回填已落地的桥接：产品采用独立 Swift 可执行程序 `native/dock-runtime.swift`，通过受限、逐行 JSON 向主进程发送 Dock 轮廓数值；ScreenCaptureKit 像素保留在 helper 内。诊断 helper `src/platform/native/dock-live.swift` 保持独立身份。该方式避免 Node 原生扩展的 ABI 绑定，但仍需维护 Swift 构建、子进程生命周期、协议校验、权限归属和每次重签后的真机验收；不得退回固定 Dock 边界冒充捕获成功。

两个 helper 均以 `arm64-apple-macos15.0` 编译，应用 `LSMinimumSystemVersion` 因而同步为 `15.0`，避免系统允许一个缺少可运行原生能力的包启动。此值是构建／加载下限，不是全部 macOS 15 及以上桌面行为的支持声明。当前联合验证与资源样本的具体硬件、系统、缩放和未通过项目记录在根目录 README 的 #11 交付记录；精确依赖继续以 package.json 和 pnpm-lock.yaml 为准。用户已确认先测资源基线、预算待确认，测量不自动产生“低功耗”或性能达标结论。
