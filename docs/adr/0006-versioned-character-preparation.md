# 用统一描述和不可变资源快照准备角色

角色身份、展示名称与资源版本分开：保留 `whale` 作为旧偏好的稳定标识，默认展示名称采用 DeepSeek；资源版本由准备后的描述与实际图片内容共同确定。内置素材在构建时整理成与用户数据目录相同的准备后契约，主进程统一读取并校验，设置、行为、绘制和点击判定据此工作。这个契约承接后续导入加工的产物，不等同于面向作者的 ZIP 源素材规范。

主进程在一次准备中持有不可变图片字节和几何描述，通过受限的图片协议交给渲染进程；握手与渲染缓存同时区分请求、渲染代次、角色身份和资源版本。它放弃了渲染端按角色独立枚举构建资源的方式，以保证同标识更新和渲染恢复使用一致的图片与命中数据，代价是准备期间需要同时持有当前版本与候选版本的资源。成功准备并保存选择后才替换当前角色，取消或失败保留当前快照并释放候选资源。

基础动作统一为待机、行走、拖拽、下落和着陆；扩展行为的姿态依赖集中定义并用于校验和行为选择。不完整的扩展组合拒绝加载，完全缺少的扩展能力不会触发。无攀爬素材的角色可以落到下方支撑，但不因新出现或上移的 Dock 边缘向上攀爬。
