# Issue #15 — 自由活动

实现基于 integration/issue-15-autonomy 的 `14bdb46`（包含 #4 拖动和 #6 手动隐藏）。验收边界沿用规格 #1 Testing Decisions：真实 Electron 应用的 Canvas、窗口实际位置和公共菜单，不查询行为机私有状态，也不新增运行时测试开关。

## 行为与调优

`src/behavior/resting.ts` 保持纯 TypeScript，XState 表达休息、行走、伸展、自己玩及暂停；既有点击、拖动与下落路径保留。每次稳定休息等待 18–32 秒，活动选择概率为行走 45%、伸展 30%、玩耍 25%。行走 2.4 秒、最多 150 桌面点；参数集中于 `autonomy`，动作帧时长位于素材制作表，没有新增设置。睡觉属于 #5。

主进程按当前主屏 workArea 约束位置，走路始终沿地面，边缘向内转身。Canvas 与命中区域都跟随方向镜像。按下自主活动中的身体立即停止原行程；点击开始互动，拖动沿用 #4 返回地面的动作。持住身体期间暂停下一次自主活动；释放或取消后重新计时。actionId、退出状态时取消 XState 延迟以及每次运动的身份检查共同隔离过期完成事件和运动回调。

隐藏及 suspend/lock 取消活动与运动，渲染呈现为隐藏；恢复从稳定休息重新安排整段等待，不追赶过期动作。每帧根据经过时间选图；渲染器使用 timeout 等待下一素材帧边界，再由 requestAnimationFrame 执行 Canvas 工作；初次呈现直接请求 rAF，隐藏、页面退出及呈现变化同时取消独立的 timeout 与 rAF。待机约每500ms绘制一次，不会每次显示刷新都唤醒。既有 8ms 鼠标路由轮询仍存在，不能据此声称整应用低功耗。

最终 `tests/autonomy.test.ts` 从真实应用输出采集完整待机循环及其镜像作为参照，排除朝向改变和动作最初的待机姿态。伸展／玩耍等待出现真实非待机画面，再等待450ms捕捉明确低头伸展／抬爪动作。覆盖短距离移动、地面位置、点击停止旧行程、拖动打断活动、抓住期间无旧回调拉回、边缘向内、隐藏不移动、恢复无补播、系统暂停停止绘制及长按不启动步态。

自动化只在系统时间／随机数边界缩短 ≥10秒的休息延迟为1秒；运动和素材帧时间保持真实。暂停／恢复用 Electron 的系统事件模拟；鼠标输入是 Playwright 针对宠物窗口的输入，不等同跨应用真实首次点击，也不是物理机器休眠唤醒的证明。默认节奏、实际睡眠唤醒、长期 CPU／内存／耗电以及主观自然度需单独真机试用。
