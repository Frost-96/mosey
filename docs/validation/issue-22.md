# Issue #22 — 宠物本体上下文菜单

基线为 `c5a8b1f`，包含已交付的 #4 拖动、#6 隐藏与 #15 自由活动。菜单仅含 Hide Mosey 与 Quit Mosey；诊断入口仍在菜单栏。没有占位设置项。

## 实现边界

渲染器把右键／Control-click 的 contextmenu 发送为既有受限 input 通道上的严格类型事件；普通左键处理排除 Control。主进程重复校验发送者、可见性、当前可见像素命中及动作身份。拖动捕获期间忽略辅助点按。菜单使用 Electron 原生 Menu，在经过命中校验的局部坐标处弹出，由系统处理屏幕边缘避让；提供所属 frame，并仅在用户打开本体菜单时激活应用。

本体隐藏与顶部菜单共用同一持久化可见意图操作，退出共用既有清理路径。行为模块不引用 Electron 或菜单对象。纯 TypeScript Timeline 为 XState 延迟、互动时间戳、行走和下落提供同一活动时间；菜单期间冻结时间，关闭后扣除暂停长度。渲染器暂停所有绘制调度，保留最后可见 Canvas，恢复时沿原动作进度继续。冻结期间不消耗完成事件；过期动作身份仍由原契约隔离。

隐藏、系统暂停、显示配置变化及退出显式解除菜单暂停，不依赖 OS 必然回调。晚到的原生回调按菜单身份隔离；同步弹出异常记录日志并恢复。没有新增任意 IPC 频道或运行时测试开关。
