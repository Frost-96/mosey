# DeepSeek（鲸鱼娘）素材

DeepSeek 沿用 `whale` 标识。当前采用的动作图集在 `sprites/`，构建配置在 `processing.json`，来源、原图、参考图与完整生成请求见 `adoption.json` 和 `provenance/`。运行 `pnpm assets:build` 生成应用加载的图集。

`source/`、`reference/`、`generation-record.json`、`actions-generation-record.json` 和 `processing-notes.md` 保留早期素材的来源记录，其中部分待机及互动姿势继续沿用。当前构建以 `processing.json` 为准。

早期记录将角色归于 schrieeeffer/shenshen-codex-pet，并记载非商用与署名条件；这里保留该来源记录，不将生成式重绘视为取得公开或商业发行授权。
