# 鲸鱼娘样片素材

待机与行走在 #48 获得用户确认，作为后续动作的造型与流畅度基准。#49 增加完整通用动作；新动作的制作依据见 `actions-generation-record.json` 与 `processing-notes.md`，完整视觉与真实桌面结论仍须分别记录。

## 角色设定

沿用用户偏好的 B 头身比例方向：头约占全身一半，深蓝长发与蓝色发梢、蓝眼睛、鲸鳍耳、鲸尾、白色波浪发箍、深蓝裙、白围裙和蓝鲸标志、白袜与深蓝鞋。身份由 `reference/idle-hd.png` 锚定；提示词不等于模型已准确遵从。

## 来源与实际输入

- 既有素材来自先前保存的 `whale-hd-remake` 预览成果，旧待机／走路／挥手图、提示词和预览网格保存在 `reference/`。旧三组草稿并非最终采用版本。
- 旧记录指向 [schrieeeffer/shenshen-codex-pet](https://github.com/schrieeeffer/shenshen-codex-pet)，并记载非商用与署名条件。本轮未独立核验上游授权，不把生成式重绘视为取得公开或商业发行授权。本项目此阶段仅本地验收。
- `generation-record.json` 保存本轮实际提交的完整提示词、引用图和透明参数。新候选的实际输入就是仓库内保留的 `reference/idle-hd.png`。模型版本和 seed 未由工具提供，保留未知。
- 旧提示词提到 Original B 与 remake，但确切输入图对应关系缺失；不能补写成确定事实。原临时交接文件已失效，本轮使用持久成果恢复可验证来源。
- `source/idle-v1.png` 与 `source/walk-v2.png` 为新候选原图。PNG 自带 alpha。没有为增加帧数复制图片，没有用混合、变形或算法插值冒充新姿势。

## 加工与播放

候选原图均为实际 1774×887，按 4×2 网格的四舍五入边界取帧。`processing.json` 保存逐帧精确 region、锚点与时长。待机与行走采用 0.95 比例进入 2x 素材坐标；新增原图按 `processing-notes.md` 分别固定整体缩放。跨原图过渡可覆盖 source 和 scale，同一原图的 scale 必须一致，不逐帧改变身材。

待机与行走的水平注册点来自面部肤色区域的中心（仅用于对齐，不是身体最左边或轮廓中心）；垂直注册点取 alpha≥128 的最底端鞋底。新增动作的注册方法见 `processing-notes.md`，仰躺睡眠使用轮廓中心以避免支撑部位改变产生横跳。输出统一脚底基准，由构建脚本生成绘制图集及同源透明命中数据。低 alpha 边缘处理、最终裁切和路径以构建脚本为准。

待机按 1500、400、60、45、90、45、60、600 ms 播放，共 2800 ms；走路按 8×90 ms 播放，共 720 ms。旧待机为 1100 ms，旧行走为 1060 ms，均为时序记录而非渲染性能。

行走建议每周期移动 84 个 2x 素材像素（240 DIP 宠物窗口下为42 DIP）；这是测量支撑鞋相对身体在接触→经过阶段约41源像素后取两步得到的初始调参值，尚非人工确认的无滑步结论。随现有宠物大小等比缩放。不得使用固定画框播放代替实际横向移动验收。

## 当前限制

新行走候选增加了明显抬脚和经过姿势，但交替承重、裙摆变化、循环接缝及跨动作转身仍需正常速度观察和用户判断。第一版12帧步行因姿势相似和边缘过紧弃用；第三版侧脸候选因跨动作造型差异弃用；其提示词与弃用原因保留在生成记录中。

本包覆盖共享行为的 16 个表现动作，包括自然活动、互动、睡眠、拖起、下落、落地和攀爬。动作映射与合理帧复用见制作说明；待机只用于明确的起止过渡，不代替缺失动作。本阶段仍通过隔离入口验收，正式设置选择留给 #50，正常启动仍默认柯基。
