# 通用动作加工记录

沿用 #48 用户已确认的 `source/idle-v1.png` 作为本轮五张原图的实际输入；完整提示词与参数见 `actions-generation-record.json`。所有图均由内置 image_gen 生成，模型版本和 seed 未提供。新增动作仍需本地视觉与真机验收。

`processing.json` 为最终构建依据，覆盖16个共用行为动作。各源图实际尺寸均为1774×887。不能仅按名义等分网格截帧：例如睡眠上下行分界采用透明间隙中部，保留站立帧脚底。逐帧 region 已按实际透明间隙测量，原图完整保留。

新增源图按鞋底（坐姿为最低支撑轮廓）最下8行不透明像素的平均横坐标加4源像素注册，垂直注册至alpha≥128轮廓最低边界。固定偏移与既有待机脚底基准配合；行走继续保留已确认的身体注册方式，避免把腿部相对运动消除。绘制和hitRows由同一构建像素生成。

每张源图使用固定缩放：sleep-v1 .90；reactions-v2、leisure-v1、motion-v1 .935；ground-v1 .93。已有idle-v1保持.95。帧级scale只用于跨源图复用固定缩放，不对同一原图中的单帧改变身材。所有输出脚底统一为2×素材坐标(240,480)。

| 共用行为          | 人形表现与采用姿势                                                            |
| ----------------- | ----------------------------------------------------------------------------- |
| settling / waking | sleep 0–5的站立、屈膝、坐下、闭眼；醒来反向衔接已确认待机                     |
| sleeping / ear    | sleep 6–7坐姿呼吸与轻微鲸鳍／发梢变化；睡中反应320ms，保留900ms二次点击窗口   |
| tilt / paw        | reactions 0–3好奇歪头；4–7挥手                                                |
| belly / playing   | leisure 0–3开心致意；一次点击与自主轻玩分别采用不同停留节奏，合理共享真实姿势 |
| stretching        | leisure 4–7抬臂伸展，首尾回到待机                                             |
| dragging          | motion 0–1被提起时收拢四肢                                                    |
| flutter / falling | motion 2–4短暂张臂平衡，5–7下落准备                                           |
| landing           | ground 0–3屈膝缓冲、伸直恢复，接待机                                          |
| climbing          | ground 4–7伸手、提膝、踏上、站稳；实际位移由既有Dock逻辑管理                  |

循环／结束规则和全部时长均记录在processing，不以统一倍速替代姿势变化。首尾复用待机只用于真实过渡，不填充未制作动作。底层动作标识沿用既有共享行为名，不要求鲸鱼娘做犬类翻肚或伸爪。

透明边缘先按既有阈值移除低alpha碎边，裁至有效轮廓后统一缩放并置于480×480框；构建超框时报错，不静默裁掉头发或尾巴。来源与使用范围继续遵守角色README中的本地验收限制。
